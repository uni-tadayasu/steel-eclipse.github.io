# STEEL ECLIPSE — FUSION RECORDS
## PC・スマホ兼用 / ソロ・協力・対戦対応

**ゲーム本体:** `index.html`  
**通信サーバー:** `server.js` と `frames.json`  
**Windowsでマルチプレイを起動:** `Windows_マルチ起動.bat`  
**Mac / Linuxでマルチプレイを起動:** `start_server.sh`

このゲームは、歴代ロボット作品の造形思想をヒントにした**独自デザインの融合メカ**を操縦する、非公式のWebゲームです。公式機体そのものの3Dデータ・写真・画像は含みません。機体は手作りのコードで立体描画します。高度なWebGLが使えない環境では、2D描画に切り替わります。

## 収録内容
- 初期から**全40機体が使用可能**。最初の機体は大型四翼ユニット「ノヴァ・マンサ」。ロックや購入費用はありません。
- **48ステージ / 6作戦セクター**。全ステージ初期選択可能。ステージごとにボス・テーマ・敵部隊・報酬・難易度を設定。
- **1人ソロプレイ / 2～4人のオンライン協力 / 2～4人のオンライン対戦（最後まで生き残る方式）**。
- PCはキーボード・マウス、スマホは画面内のバーチャルスティックと操作ボタン。
- 5系統の改造、各最大30段階。戦績とCRと強化は使用端末のブラウザ内に保存します。
- プレイヤー名は上部の「PILOT / 名前変更」から設定。画面左上などに表示されます。

## 1. ソロプレイ（インターネット不要）
`index.html` をChromeまたはEdgeで開き、**格納庫から機体を選ぶ → 作戦 → 出撃**で遊べます。サーバーは不要です。

> ブラウザのWebGL機能が使えない場合は自動で2Dに切り替わります。独自形状のため、プロ制作のフォトリアルGLBと同一の再現度を保証するものではありません。

## 2. PCとスマホを同じWi-Fiでマルチプレイ
1. Windows PCに **Node.js 22以降** をインストールします。https://nodejs.org/  
   *サーバーには外部npmパッケージが不要です。*
2. ZIP内を**すべて同じフォルダへ展開**します。`Windows_マルチ起動.bat` をダブルクリック。ターミナルにサーバーのURLが表示されます。窓は閉じずに置きます。
3. PCで `http://localhost:3000/` を開きます。
4. Windowsで `ipconfig` を実行し、Wi-Fiの**IPv4アドレス**を調べます。たとえば `192.168.1.10` だったら、スマホのブラウザで `http://192.168.1.10:3000/` を開きます。※ `192.168.1.10` は例です。ご自身のPCアドレスに置き換えてください。
5. PCとスマホの両方で「オンライン / 対戦」へ進み、名前を入力。ゲームにアクセスした同じサーバーの `ws://.../ws` が接続先として自動入力されます。
6. PC側が「協力作戦」か「対戦」を選んで**新しい部屋を作成**します。スマホ側は**表示された6文字コードで参加**します。
7. 2人以上集まったら**部屋主が「全員で出撃する」**を押します。機体は格納庫で出撃前に選択できます。最大4人までです。

### 繋がらない場合
- PC・スマホが同じネットワークにつながっているか確認（スマホがモバイル回線だと別ネットワークです）。
- Windows Defender ファイアウォールで、Node.jsのプライベートネットワーク通信を許可してください。ポートはTCP **3000** です。
- 別のプログラムが3000番ポートを使っている場合は環境変数`PORT`を変更して起動し、アクセスするURLのポート番号もそろえてください。
- **「ファイルを直接開く」方式と「同じWi-Fiで公開する」方式は異なります。** PC/スマホで部屋を共有するなら、両者がPC上のNodeサーバーからゲームを開くのが確実です。

## 3. 遠隔地の友人とプレイ
離れた場所を繋ぐには、このNode.jsサーバーを**公開可能なホスティング環境**に配置し、HTTPS/WSSで接続できるように設定してください。サーバー起動コマンドは `npm start` または `node server.js`、必要なポートは `process.env.PORT` に自動対応しています。Web上の通信URLは通常、ページと同じホストの `wss://ホスト名/ws` になります。

**GitHub Pagesだけで動作するのはソロプレイ部分**です。GitHub PagesではNode/WebSocketサーバーを実行できないため、遠隔協力/対戦には別サーバーが必要です。

## 5. 技術と制限
- フロントエンド：1ファイルのHTML/CSS/JavaScript、自作のWebGL/Canvas描画。
- サーバー：Node.js標準モジュールを利用したWebSocketサーバー（追加ライブラリ不要）。同時参加は1ルーム最大4人。
- 協力戦：**部屋主が敵部隊の行動を処理**し、敵位置・HPを同室へ定期配信。ゲストの敵への攻撃を部屋主に送ります。
- 対戦：**HPとダメージはサーバー側で処理**しますが、商用ゲーム並みのチート対策、衝突判定検証、遅延補償は含まれません。
- ルーム情報はサーバーのメモリ上のみ。再起動すると部屋は消えます。強化・戦績はブラウザの`localStorage`です。端末間で戦績は同期されません。
- 公式のガンダムブランド・作品・制作会社との関係はありません。ネット上の写真・公式3Dモデルを無断ダウンロード・埋め込みしていません。
- 一般公開する際はHTTPS/WSS、アクセス制限、サーバー監視、悪用防止、プライバシーポリシー等をご自身で追加してください。

## 6. 制作者向け

```bash
node --version
node server.js
```

ブラウザで `http://localhost:3000/`。サーバー稼働確認は `http://localhost:3000/health`。
