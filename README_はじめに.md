# STEEL ECLIPSE — REFORGED RECORDS

**独自設計の巨大ロボット40機・48作戦を遊べる、PC／スマートフォン対応のWebアクションゲーム。**
架空の機甲設計工房の図面・整備マニュアルをモチーフに、サイト・格納庫・戦闘画面を制作した改修版です。

## フォルダの内容

- `index.html` — ゲーム本体。ソロはこれだけで起動できます。
- `server.js` — PC・スマホで協力／対戦するための部屋サーバー（Node.js標準機能のみ）。
- `frames.json` — 40機体のサーバー側パラメータ。
- `Windows_マルチ起動.bat` — Windows用のサーバー起動ファイル。
- `start_server.sh` — Mac/Linux用のサーバー起動ファイル。
- `package.json` — Node.jsの起動用設定。
- `README_はじめに.md` — 本説明書。

## 今回の改修（REFORGED）

1. **専用機体のディテール強化**：初期機体「ノヴァ・マンサ」などのオリジナル機体を、装甲面の面取り、胸部装甲、関節、バインダー裏の発光部、翼、フィン、背部推進器などの追加3D形状で拡張しました。造形はプログラム生成であり、既存アニメの公式モデルの複製ではありません。
2. **環境の描画強化**：48作戦（16の環境テーマ）について、街区・雪山・砂漠・施設群・宇宙を思わせる戦場設備や、天候粒子、地形の背景表現を強化しました。2D互換描画でもステージごとの背景が変わります。
3. **操作感・戦闘演出**：機体の慣性・氷や砂地の路面差、照準・攻撃ヒット演出、連続ヒット表示、危険時表示、合成エンジン音、被弾時のカメラ揺れ（設定からON/OFF）を追加・調整しました。
4. **完全再設計したサイト画面**：既製の光るカードUI風ではなく、架空の整備工房が制作した機体記録簿をイメージした深緑・銅・紙色のデザインに変更。機体台帳、型式表示、作戦のカード、強化画面、通信室、戦闘HUDを統一しました。
5. **画質・設定画面**：描画精度（精密／標準／軽量）、合成効果音、天候、カメラ揺れ、視点感度、フルスクリーンを設定できます。スマホで重い場合は「軽量」を推奨します。
6. **既存の遊び方を維持**：40機全機体初期解放・48作戦の選択・機体強化・プレイヤー名・ソロ・2〜4人協力・2〜4人対戦（PvP）・ブラウザ保存に対応します。

## 1. ソロプレイ

`index.html` をChrome / Edgeなどで開きます。機体は最初から40機選べます。格納庫で選択して「作戦」から出撃します。サーバーは要りません。

- **PC**：W/A/S/Dで移動、左クリックまたはJで射撃、Kで格闘、Lで必殺技、Shiftでダッシュ、Spaceでジャンプ、Q/Tabでロックオン切替、Eでガード、1/2/3で武器変更、右ドラッグで視点操作、Esc/Pで一時停止。
- **スマホ**：画面左側のスティックで移動。右側に射撃・格闘・ダッシュ・ジャンプ・必殺技・ロックオン・ガード・武器変更ボタン。空いている画面をドラッグして視点を調整できます。

ゲームのセーブは端末のブラウザの `localStorage` に保存されます。端末やブラウザを変える場合は「戦績」ページのセーブ書き出し／読み込みを使ってください（自動同期ではありません）。

## 2. PCとスマホで同じWi-Fiから協力／対戦

1. Windows PCに [Node.js](https://nodejs.org/) の22以降をインストールし、ZIPを展開します。
2. 展開したフォルダ内で `Windows_マルチ起動.bat` をダブルクリックします。Node.jsだけで起動するので `npm install` は不要です。
3. PCのブラウザでは `http://localhost:3000/` を開きます。
4. Windowsのコマンドプロンプトで `ipconfig` を実行して、PCのWi-FiのIPv4アドレスを確認します。たとえば **192.168.1.10** なら、スマホのChrome/Safariで `http://192.168.1.10:3000/` を開きます（IPは例です）。
5. 両方の画面で「オンライン／対戦」からそれぞれプレイヤー名と機体を設定。ホストが「協力」または「対戦」の部屋を作り、スマホ側は6文字のコードで部屋に参加します。
6. 2～4人が参加したら部屋主が出撃します。協力では4ウェーブとボス、対戦では最後の1機になるまで戦います。

**接続できない場合**：両端末が同じネットワークか、Windows DefenderファイアウォールでNode.jsのプライベートネットワーク接続を許可したか、TCP 3000を別プログラムが利用していないかを確認してください。起動したウィンドウは閉じないでください。

## 3. 離れた場所のプレイヤーと接続

公開サーバーで `node server.js` を起動し、HTTPSとWSS（WebSocket TLS）に対応するリバースプロキシを設定してください。`PORT`環境変数でポートを変更できます。インターネット公開用のサーバーやURLは配布物に含まれていません。**GitHub Pages単体ではサーバーを起動できず、オンライン協力・対戦は使えません。**

## 4. 技術的な制限（重要）

- 機体3D表現は自作の手続き的な形状・独自の光表現によるものです。アニメ作品の原画／写真／公式モデルを完全再現するものではなく、商用AAAレベルのフォトリアル・PBRレンダラーでもありません。
- WebGLが使えないブラウザ／GPUでは**2D互換表示**で動きます。WebGLでの本格3D描画は対応端末で使用してください。戦場の描画品質と動作速度は端末によって変化します。
- ルーム情報はサーバーのメモリ上で管理されます。再起動後に部屋は消えます。サーバーは単純なルーム同期向けで、一般公開運営に必要なアカウント認証、不正接続・不正操作対策、遅延補償、モデレーションは搭載していません。
- PvPのHP・ダメージはサーバー側で処理しますが、移動／照準はクライアントが申告するため、対戦大会などの厳密な公平性は保証しません。
- 他作品の制作会社・版権元と本ゲームに関係はありません。機体はオリジナル創作です。任意で提供される外部CC0モデル表示はゲーム内部のオリジナル機体そのものを置き換えるものではありません。
