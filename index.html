02 — FIELD MANUAL

設計ノート。

本作は既存の公式3Dモデルの転載ではありません。架空の試験機を、装甲ブロック・先端の面取り・メカニカル関節・バインダー・フィン・推進器を組み合わせて描画します。40機の骨格には共通の設計言語があり、型式ごとに追加の外装と兵装が分かれます。

演出 — 金属の反射 / 擬似的なエッジ光 / 発光装甲 / 戦場環境音 / レーダー / 被弾反応
作戦 — 48地点・16種類の環境モチーフ / 4ウェーブとボス / ソロ・協力・対戦
移動 — 慣性・ダッシュ・ジャンプ / 衝突判定 / 武装冷却とシールド

これは独自プログラムによるスタイライズド3Dです。商用AAA作品のフォトリアル映像、物理演算、サーバー同期と同等ではありません。実際の表示は端末性能とWebGL対応に依存します。

スマートフォン 操作

左のバーチャルスティックで移動。右の FIRE ボタンで射撃、SLASHで格闘、DASHで高速移動、BOOSTでジャンプ、SPで必殺技、GUARDで防御。画面上をなぞると視点を回転できます。

戦闘ルール

敵機と4ウェーブを攻略して大型ボスを撃破。CRを入手して機体を最大30段階まで強化できます。全40機・全48作戦は初期開放済みです。オンラインでは協力攻略と対人戦が選べます。

3Dモデルと素材

機体・背景・エフェクトはWebGLで独自に生成します。実在作品の3Dモデルや写真は含みません。音はWeb Audioによる合成音です。
